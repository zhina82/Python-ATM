# Python ATM

A simple ATM simulation project developed with Python.

## About the Project

This project simulates basic banking operations through a command-line interface (CLI).

The current version uses a CSV file to store account information. The project demonstrates Object-Oriented Programming (OOP), file handling, input validation, and basic bank account operations.

## Features

* Create a new bank account
* Generate a unique account number
* Login using an account number
* Deposit money
* Withdraw money
* View account balance
* Update personal information
* Transfer money between accounts
* Validate user inputs
* Store account data using CSV
* Prevent transfers to the same account

## Technologies

* Python
* CSV
* Object-Oriented Programming (OOP)
* Git & GitHub

## Data Storage

The current version uses a CSV file for data persistence.

The project can be extended in the future by replacing CSV storage with a database such as MySQL.
